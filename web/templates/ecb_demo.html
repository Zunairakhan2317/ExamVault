ECB vs GCM

ECB is insecure and is never used in ExamVault

The same picture is encrypted with the same AES key in two modes. ECB encrypts every 16-byte block on its own, so identical blocks give identical ciphertext and the picture's outline survives. GCM uses a fresh random nonce and also authenticates the data, so the result looks like noise and any change is detected. ExamVault encrypts every paper with AES-256-GCM.
